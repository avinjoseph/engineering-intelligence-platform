# New Engineer Onboarding

## First week checklist
- Get access to Slack, GitHub org, and the internal wiki
- Set up your laptop using the standard dev environment script
- Meet with your onboarding buddy for a codebase walkthrough
- Read the on-call rotation guide before your first on-call shift

## Requesting access
Access to production systems (Kubernetes, databases, cloud console) requires
manager approval via the internal access-request tool. Approval typically
takes 1-2 business days.

## Company holidays
The company observes standard national holidays plus two floating holidays
per year, which can be used at the employee's discretion.
